# JZ Linen & Laundry

Local development project for the JZ Linen & Laundry website.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` checks code style and lint rules.

## Local Data

Bookings, user signups, and the admin session are stored in browser local storage on the current device.
